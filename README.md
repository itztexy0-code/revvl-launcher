# Revvl Launcher

A Nova-style home screen for Android (min Android 8.0 / API 26):

- Swipeable home screen pages (add/delete pages, put apps and folders on them), clock, dock (5 slots), swipe-up for the app drawer
- App drawer with search, "+ Folder" button, folders
- Long-press any app: rename, change icon (pick an image from your gallery, circle or square), reset, add to / remove from folder, add to / remove from dock, app info, uninstall
- Long-press a folder: rename, change icon, reset icon, delete
- Long-press empty home screen: add/delete page, icon size slider, home/drawer columns, wallpaper

No third-party libraries. Build is done by GitHub Actions (.github/workflows/build.yml).
