# Revvl Launcher

A Nova-style home screen for Android (min Android 8.0 / API 26):

- Home screen with clock, date, dock (5 slots), swipe-up (or tap the handle) for the app drawer
- App drawer with search, "+ Folder" button, folders
- Long-press any app: rename, change icon (pick an image from your gallery), reset, add to / remove from folder, add to / remove from dock, app info, uninstall
- Long-press a folder: rename, change icon, reset icon, delete
- Long-press empty home screen: change wallpaper, drawer columns (3/4/5)

No third-party libraries. Build is done by GitHub Actions (.github/workflows/build.yml).
